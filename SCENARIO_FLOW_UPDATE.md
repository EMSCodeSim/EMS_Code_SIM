# Scenario Flow Update — v1.5.0

- Visual Patient is the permanent scenario home.
- Removed automatic four-second advancement after saving findings.
- Added dynamic recommended-next-action coaching.
- Added treatment access during primary assessment and patient information gathering.
- Added automatic reassessment prompts after treatment.
- Renamed Vitals to Tools and Findings to Log.
- Added Assessment, History, and Reassessment log filters.
- Replaced the launcher’s long required checklist with seven broad clinical phases.
- Scenario completion no longer requires every available simulator; handoff completion is the required finishing point.
