# Vitals Tab Separation Update

## Changes

- Renamed the former **Tools** bottom-navigation tab to **Vitals**.
- Removed blood pressure, pulse, respiratory rate, SpO₂, blood glucose, and temperature from the Assessment menu.
- Kept partner assignment, countdown, queued-task status, completion status, and reassessment links inside the Vitals tab.
- Kept the Assessment tab focused on scene size-up, rapid ABC, focused physical assessments, SAMPLE, and OPQRST.
- Added a validation test that prevents measurable vital tools from being added back to the Assessment menu accidentally.
