# State-Aware EMS Career Planner Update

## Added
- State selection for all 50 states and Washington, DC
- Optional Colorado region selection
- Location-aware recommendations on the main pathway dashboard
- Colorado EMT-to-paramedic pathway with IV approval, Basic ECG, anatomy/physiology, BLS, experience, and program-comparison milestones
- Colorado course/resource links that change by region
- Official state EMS office and accredited-program resources for other states
- State and region included in printed career reports and backups

## Important
Colorado is the first fully researched state pathway. Recommendations are planning guidance only. Course dates, admission requirements, scope, and certification rules can change; users must verify them with the state, school, and employer.
