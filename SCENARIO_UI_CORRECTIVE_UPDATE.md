# Scenario UI Corrective Update 1.10.0

This consolidated update fixes the deployment mismatch that left the older launcher and Transport bottom tab visible.

## Included
- Picture-first launcher with mode selection after tapping a scenario image
- Continue or reset for an active scenario
- Assigned Scenario hidden from the launcher
- Bottom bar: Assessment, Vitals, History, Treatment, Log
- Patient interview workspace and known-history tracking
- Five-column phone navigation
- Cache-busted assets and no-cache rules for scenario UI files
- Root compatibility redirects for legacy launcher URLs
- Visible `Scenario UI 1.10` / `UI 1.10` build markers
