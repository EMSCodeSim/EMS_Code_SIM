# Scenario Stop and Reset Controls Update

- Adds an always-visible Scenario menu in the patient header.
- End and save stops the active call and returns to scenario selection without deleting progress.
- Reset and restart clears all patient findings, vitals, treatments, transport decisions, partner tasks, and care-log events for that scenario.
- Uses a phone-friendly bottom sheet instead of browser alert/confirm dialogs.
- Existing End/Reset buttons in Scenario Progress open the same safe control sheet.
