## What changed
Each module is designed as an approximately 30-minute guided lesson with:
- a timed lesson plan and optional 30-minute timer;
- deeper foundational content and applied examples;
- learning objectives and section estimates;
- a saved reflection or planning activity;
- a five-question knowledge check with explanations;
- optional authoritative resources;
- a future-app support section;
- existing saved module-completion tracking.

This remains a free pre-course readiness resource. It does not replace a state-approved EMT course, hands-on skills instruction, local protocols, certification, or medical direction.
