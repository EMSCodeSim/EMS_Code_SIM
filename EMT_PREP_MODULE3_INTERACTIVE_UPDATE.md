# EMT Prep Module 3 Interactive Upgrade

Module 3 was redesigned as a 75–95 minute medical-terminology laboratory.

## Added
- Medical word-parts simulator
- Prefix recognition trainer
- Complete-term decoder simulator
- Anatomical-direction simulator
- EMS abbreviation safety trainer
- Plain-language and objective-wording simulator
- EMS-note capstone using only previously taught terminology
- Seven lesson-specific quiz questions
- Four instructional PNG images with editable SVG source files
- Local progress and response storage

## Teaching rule
Every term, abbreviation, and directional concept is defined and demonstrated before it appears in a simulator, scenario, capstone, or quiz.
