# Scenario Selection Mode Menu Update

Version 1.9.0 changes the patient scenario launcher to a picture-first selection flow.

## Changes

- Each scenario is presented as a patient picture card.
- Tapping a picture opens a focused scenario menu.
- The learner chooses Learning Mode or Assessment Mode after selecting the patient.
- The active patient card is marked **In progress**.
- A saved scenario can be continued from the selected-patient menu.
- A saved scenario can be reset before a new mode or patient is started.
- Starting another patient no longer silently overwrites the active call.
- The Assigned Scenario banner and assignment-selection behavior are hidden from the launcher.
- The mode and resume menu is optimized as a bottom sheet on phones.
